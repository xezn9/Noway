# Liquid Bar Demo

Android Studio project that shows the standalone liquid-glass bottom bar (`LiquidBottomBar.kt`).

1. Open this folder in Android Studio (latest stable). Let it sync (it downloads Gradle 9.5.0 and Android SDK 37 if missing).
2. Run on a real device or emulator. Android 13+ (API 33) shows the full refraction effect; Android 12 shows blur only.
3. Drag/press the selected capsule to see the glass effect.

`LiquidBottomBar.kt` is derived from Kyant0/AndroidLiquidGlass (Backdrop 2.0.0) and Kyant0/Shapes, Apache-2.0. See the header in that file.
